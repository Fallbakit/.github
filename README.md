Fallbakit is a smart proxy layer that sits between a developer's application and their AI models. It exposes an OpenAI-compatible API, routes inference to the user's local Ollama, oMLX, or vLLM runtime by default, and falls back to cloud providers automatically when local inference is offline, degraded, or unavailable. Basic subscriptions support one active local runner connection; Enterprise subscriptions support multiple active local runner connections with configurable project or organization limits.
